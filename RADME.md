# E-commerce Core

Проект представляет собой ядро для интернет-магазина, реализованное с использованием ООП.

## Функциональность

- Класс `Product` для описания товаров.
- Класс `Category` для описания категорий товаров.
- Автоматический подсчёт количества категорий и товаров.
- Тесты для проверки корректности работы классов.

## Что добавлено в этой работе

1. **Новые классы**:
   - `Smartphone` — для смартфонов. Добавлены атрибуты: производительность, модель, объем памяти, цвет.
   - `LawnGrass` — для газонной травы. Добавлены атрибуты: страна-производитель, срок прорастания, цвет.

2. **Сложение товаров**:
   - Теперь можно складывать только товары одного класса (например, два смартфона).
   - Если попытаться сложить товары разных классов, выбросится ошибка.

3. **Добавление товаров в категорию**:
   - Теперь можно добавлять только товары или их наследники (смартфоны, газонную траву).
   - Если попытаться добавить что-то другое, выбросится ошибка.

4. **Тесты**:
   - Добавлены тесты для новой функциональности.
   - Покрытие кода тестами — больше 75%.

## Как запустить тесты

```bash
# Установите зависимости
pip install pytest coverage

# Запустите тесты
coverage run -m pytest

# Посмотрите отчет о покрытии
coverage html
